Python solutions to LeetCode problems, written while learning data structures & algorithms from scratch.


Structure

It has Folders for each problem in which there will be 2 files ,a brute force solution and an optimized solution. Some problem folders might have only one file for the optimized solution in case the optimized solution clicks first while writing the code.


Notes

Starting with brute-force solutions to build intuition, then optimizing once the logic is solid.
Not aiming for speed, aiming to actually understand each solution before moving on.
